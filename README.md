
# Student Registration Application

A simple Student Registration Application developed using React.

## Features
- Enter student Roll Number
- Enter student Name
- Enter Email Address
- Enter Branch
- Enter Mobile Number
- Validate student details
- Display registered students in a table

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run

1. Install Node.js.
2. Open the project folder in CMD.
3. Run the following command:

   npm install

4. Start the application:

   npm start

5. Open http://localhost:3000 in your browser.
